# Memory Index

Đọc mặc định cho `Project Task`:

- `AGENTS.md`
- `docs/PROJECT_BRIEF.md`
- `docs/MEMORY_INDEX.md`

Đọc thêm theo nhu cầu:

- `docs/STACK_DECISION.md`: khi bàn lại kiến trúc OpenClaw/API/browser automation/Pancake.
- `docs/DECISIONS_INDEX.md`: khi thay đổi quyết định kiến trúc còn hiệu lực.
- `docs/modules/fb-webhook.md`: khi chỉnh webhook, LLM reply, Telegram admin bot, comment moderation.
- `docs/CHANGELOG.md`: chỉ khi cần xem lịch sử thay đổi gần đây.

Không đọc mặc định:

- Runtime logs trên VPS.
- Conversation JSON hoặc `.env`.
- Full README nếu task chỉ đụng code nhỏ.
